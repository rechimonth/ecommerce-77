# ecommerce-77

Réplica visual del Home de Zalando España, con fines educativos. Proyecto de práctica, no afiliado a la marca original.

Stack: React 18, Vite, Tailwind CSS 3 y lucide-react.

## Uso

```bash
npm install
npm run dev
```

Build de producción: `npm run build` (salida en `dist/`).

## Estructura

- `src/components/ZalandoHome.jsx`: página completa en un único componente.
- `src/App.jsx` y `src/main.jsx`: punto de entrada.
